# cam_stream.py and its helper scripts use only the Python standard library
# (hashlib, socket, os, subprocess, socket, sys, time), so there is nothing
# required to `pip install` for the core flow: probe / snap / record / play.
#
# FFmpeg (via winget) and VLC are the actual runtime dependencies and are
# installed by setup.bat, not pip.
#
# The optional packages below are only needed if you extend these scripts to
# decode or analyse frames in Python rather than shelling out to ffmpeg.
# Install with:  python -m pip install -r requirements.txt

# PyAV        direct RTSP/RTP ingest and frame decoding
# numpy       array maths on decoded frames
# Pillow      image handling
# opencv-python  computer vision on frames
# imageio     frame IO helpers
